# spec.md — 시향노트 (SCENT NOTE) MVP

## 1. 한 줄 소개

> **직접 맡아봐야 아는 향수, 그런데 뭘 맡아봐야 할지 모른다면.**
> 좋아하는 느낌을 일상어 카드로 고르면, **맡아볼 향수 3개(시향 후보)와 맡는 순서**, 각 향의 노트를 쉬운 말과 색으로 알려 주는 웹 서비스 (데스크톱 우선, 모바일 대응).

이름 뜻: '노트'는 향수의 탑·미들·베이스 노트이자, 나의 시향 기록.

---

## 2. 누가 쓰나

**타겟:** 향수를 사거나 선물하려고 매장 시향을 앞둔 사람 (향수 경험 수준 무관)

| 사용자 | 상황 | 지금 겪는 문제 (설문 근거, 향수 구매 경험자 21명) |
|---|---|---|
| **본인용 구매자** (20~30대 중심) | 백화점·올리브영에 시향하러 가기 전, 또는 매장 앞 | 원하는 향을 말로 설명 못 함(설명해 본 20명 중 "잘 통했다" 0명), 뭘 맡아야 할지 모름 (67%) |
| **선물 고르는 사람** | 받는 사람 취향을 잘 모르고, 서프라이즈라 물어보기도 어려움 | "몰라서 무난한 인기 제품" 선택 41%, 상대가 쓰는지 모름 76% |

사용 순간: **시향하러 가기 전 집이나 회사에서** 미리 후보를 정하고, **매장 앞에서는 휴대폰으로** 다시 확인한다. 그래서 **데스크톱 웹을 먼저** 완성하고 모바일 화면에서도 깨지지 않게 반응형으로 만든다. (박람회도 ZEP에서 PC 브라우저로 접속) 30초 안에 결과가 나와야 한다.

## 3. 만들 화면

### 전체 흐름
```
Home ─┬─ 나를 위한 향수 → Select(분위기 → 향기 → 피하고 싶은 느낌) ─┐
      └─ 선물할 향수   → Select(그 사람의 분위기 → 피하고 싶은 느낌) ─┴→ Result → (메모) → Notes
```

### S1. Home `/`
- 로고(3줄 마크 + 시향노트 + SCENT NOTE)
- **시향지 띠:** 14개 향 계열 색의 세로 띠 (높이 제각각)
- 헤드라인: "직접 맡아봐야 아는 향수, 무엇부터 맡아볼까요?"
- 서브: "느낌을 고르면 맡아볼 향수 3개와 맡는 순서를 알려 드려요."
- 버튼 2개: **[나를 위한 향수 찾기]**(주) / **[선물할 향수 찾기]**(보조)
- 하단 작은 링크: "내 시향 노트" (메모가 1개 이상일 때만)

### S2. Select `/select?mode=self|gift`
- 상단 단계 막대(StepBar) + "STEP n / N" (Mono)
- 하단 고정 [다음] 버튼: 최소 선택 수 미만이면 비활성 ("카드를 1개 이상 골라 주세요")
- 이전 단계로 돌아가도 선택 유지

**self 모드 (3단계)**
| 단계 | 질문 | 칩 | 선택 수 |
|---|---|---|---|
| 1 | 어떤 분위기를 원하세요? | 분위기 칩 11개 | 1~3 |
| 2 | 어떤 향기가 좋아요? | 향기 칩 14개 (계열 색 점 포함) | 1~3 |
| 3 | 피하고 싶은 느낌이 있나요? | 피하고 싶은 칩 6개 | 0~3 (건너뛰기 가능) |

**gift 모드 (2단계)**
| 단계 | 질문 | 칩 | 선택 수 |
|---|---|---|---|
| 1 | 그 사람은 어떤 분위기인가요? | 분위기 칩 11개 + **[잘 모르겠어요]** | 1~3, 또는 잘 모르겠어요 |
| 2 | 피하고 싶은 느낌이 있나요? | 피하고 싶은 칩 6개 | 0~3 |

- **[잘 모르겠어요]**: 분위기 선택을 비우고 `unsure=true` → 호불호 적은 향(`polarizing: low`) 위주 추천
- 칩 선택 상태: 분위기 칩 = 잉크 채움 / 향기 칩 = 해당 계열 `-tint` 배경 + `-deep` 글자·테두리 / 피하고 싶은 칩 = X 아이콘 + 잉크 테두리

### S3. Result `/result`
- **상단 띠:** 추천 3개 향의 계열 색 3칸 (높이 120px)
- 라벨(Mono): "YOUR SCENT NOTE · 3" / 제목: "이 순서로 맡아보세요" (gift: "이 순서로 맡아보고 골라 보세요")
- **취향 요약 한 줄:** 고른 칩을 문장으로 — 예) "차분하고 깨끗한, 비누·숲 같은 향 · 너무 단 향 제외"
- **시향 후보 카드 3개** (시향 순서대로, 순차 등장)

#### 시향 후보 카드 = 앞면 / 뒷면 (뒤집기 카드)
시향지를 앞뒤로 뒤집어 보듯, **앞면은 "이 향수가 무엇인지"**, **뒷면은 "어떻게 맡아보고 무엇을 할지"**를 보여준다.

**앞면 — 향수 정보 (맡으러 갈지 판단)**
| 항목 | 예 |
|---|---|
| 순서 번호 (Mono, 잉크 원) | 01 |
| **향수병 이미지** (API 제공, 카드 상단 중앙 약 120×160 · 모바일은 오른쪽 72×96, tint 배경 위) | 없거나 실패 시 계열 색 플레이스홀더 |
| 향 계열 태그 (tint 배경 + deep 글자) | 머스크·클린 |
| 브랜드 · 향수 이름 | [브랜드] · [향수 이름] |
| 노트 색 막대 (탑·미들·베이스 3칸) | 각 노트의 계열 색 |
| 한 줄 요약 (일상어) | 레몬 껍질처럼 산뜻하게 시작해 갓 빤 셔츠처럼 남아요 |
| 추천 이유 | 깨끗한 + 비누를 골랐어요 |
| 가격 + 용량 + 기준 | 50ml 000,000원 · 2026.10 공식몰 기준 (없으면 "해외 기준가 $000 · 100ml · [API 이름] 제공") / 작은 글씨 "가격은 변동될 수 있어요" |
| gift 모드일 때만 | "호불호 적음" 배지 (선 아이콘) |
| 뒤집기 버튼 | [노트·시향 팁 보기 ↻] |

**뒷면 — 시향 가이드 (매장에서 볼 정보 + 행동)**
| 항목 | 예 |
|---|---|
| 상단 | 순서 번호 · 향수 이름 (어떤 카드의 뒷면인지 유지) |
| 노트 3단 | TOP · 처음 10~30분 / MIDDLE · 30분~몇 시간 / BASE · 잔향 — 각 줄: 계열 색 점 + **성분명** · 일상어 묘사 |
| 잔향 한 줄 | 몇 시간 뒤엔 포근한 머스크가 남아요 |
| 강도 | EDP · 보통 (가벼움/보통/진함) |
| 호불호 | 호불호 적음 / 보통 / 호불호 있음 |
| 어울리는 계절·상황 | 사계절 · 출근 |
| 이 향의 시향 체크 포인트 | 30분 뒤 머스크가 포근하게 바뀌는지 확인해 보세요 |
| 버튼 | [시향 가능한 매장 찾기] (네이버 지도 검색, 새 탭) · [시향 메모 남기기] (S4 팝업) |
| 되돌리기 버튼 | [앞면 보기 ↻] |

**뒤집기 동작 규칙**
- 카드마다 따로 뒤집힌다. 한 카드를 뒤집어도 다른 카드는 그대로.
- 앞·뒷면 높이를 같게 고정(카드 높이 = 두 면 중 긴 쪽). 뒷면 내용이 넘치면 카드 안에서만 스크롤.
- 3D 뒤집기 애니메이션 400ms. `prefers-reduced-motion`이면 페이드 전환으로 대체.
- 접근성: 뒤집기는 `<button aria-pressed>`; 보이지 않는 면은 `aria-hidden="true"` + 포커스 불가(`inert`). 뒤집은 뒤에는 포커스를 보이는 면의 제목으로 이동.
- 첫 번째 카드만 처음 등장할 때 살짝 기울었다 돌아오는 힌트 모션 1회(뒤집을 수 있다는 신호).

카드 배경: 앞·뒷면 모두 해당 향수 주 계열의 `-tint`
결과 화면 맨 아래: "향수 정보·이미지 제공: [API 이름]" 출처 표기 (작은 caption)

- **시향 팁 박스 (카드 아래 고정):**
  1. 1번부터 가벼운 향 순서로 맡아요. 진한 향을 먼저 맡으면 코가 금방 둔해져요.
  2. 시향지에 향수 이름을 적어 두세요.
  3. 마음에 드는 하나만 손목에 뿌리고, 30분 뒤 잔향을 다시 맡아보세요.
  4. "잔향 맡아보고 올게요"라고 말하고 매장을 나와도 괜찮아요.
- 하단: [다시 고르기] · [내 시향 노트]
- 조건에 맞는 향이 3개 미만이면: 조건을 완화해 채우고 "조건에 딱 맞는 향이 적어 비슷한 향을 함께 보여드려요" 안내

### S4. MemoSheet (카드 뒷면 [시향 메모 남기기] → 팝업 + 메모 저장)
- 모바일: 아래에서 올라오는 시트 형태의 팝업 / 데스크톱: 화면 중앙 팝업
- 내용: 순서 번호·향 계열 색 점·향수 이름, 별점 1~5, 한 줄 메모(최대 100자, `<label>` 포함), [저장] · [닫기]
- 이미 메모가 있는 향수면 기존 내용을 불러와 수정 (향수당 메모 1개)
- 저장 시 팝업 닫힘 + 토스트 "시향 노트에 저장했어요" + 카드 뒷면 버튼이 [메모 수정하기]로 바뀜
- 안내 문구: "곧 시간에 따라 바뀌는 잔향까지 기록할 수 있어요"
- 접근성: `role="dialog"` + `aria-modal`, 열릴 때 별점에 포커스, ESC·바깥 영역 탭으로 닫기, 닫으면 [시향 메모 남기기] 버튼으로 포커스 복귀

### S5. Notes `/notes`
- 제목: "내 시향 노트"
- 메모 카드 목록(최신순): 계열 색 점 · 브랜드·이름 · 별점 · 메모 · 날짜, [삭제]
- 비어 있으면: "아직 맡아본 향이 없어요" + [시향 후보 찾기]
- 하단 안내 카드: "잔향 트래킹 준비 중 — 뿌린 뒤 30분, 2시간, 4시간의 향을 기록하는 기능이 곧 추가돼요"

## 4. 데이터

앱은 `src/data/*.json` 정적 파일만 읽는다. 향수 정보는 **외부 향수 API에서 미리 받아 와(sync) JSON으로 저장**하고, 한국어 설명과 국내 정가는 사람이 따로 작성해 합친다. 서버·DB 없음.

### 데이터 출처
| 정보 | 출처 | 파일 |
|---|---|---|
| 브랜드·이름·농도, 탑/미들/베이스 노트(영문), 어코드, 계절·상황 점수, **향수병 이미지 URL**, 해외 가격 | 향수 API (1순위: Fragella API) | `perfumes.raw.json` (sync가 생성) |
| 노트의 한국어 이름·일상어 묘사, 한 줄 요약, 잔향 한 줄, 시향 체크 포인트 | 직접 작성 | `perfumes.ko.json` |
| **국내 정가(원)·용량**, 기준일, 출처 URL | 브랜드 국내 공식몰에서 직접 확인 | `perfumes.ko.json` |
| 매장 검색어, 판매 채널 | 직접 작성 | `perfumes.ko.json` |
| 14개 계열 매핑 | API 어코드 → `accord-map.json` + 사람이 최종 확인 | `perfumes.ko.json`의 `family` |

**API 사용 전 확인할 것**
- 이용약관에서 **이미지 표시·데이터 캐싱(저장)·출처 표기 조건** 확인 → `decisions.md`에 기록
- 무료 플랜 호출 한도(Fragella 무료 월 20회) → 30개 향수를 받으려면 유료 플랜 또는 여러 달에 나눠 sync가 필요할 수 있음. **요금제 결정은 사용자에게 먼저 묻는다**
- API 키는 `.env.local`에만

### 스키마
```ts
type FamilyId = 'citrus'|'fruity'|'aqua'|'green'|'aromatic'|'floral'|'whiteFloral'
  |'powdery'|'musk'|'spicy'|'woody'|'amber'|'gourmand'|'leather';

/* perfumes.raw.json — sync 스크립트가 API 응답을 정리해 저장 (직접 수정 금지) */
interface RawPerfume {
  apiId: string;                  // API 상의 식별자
  brand: string; name: string;
  concentration?: string;         // EDT, EDP ...
  notes: { top: string[]; middle: string[]; base: string[] };   // 영문 노트명
  accords: { name: string; weight: string | number }[];
  seasons?: Record<string, number>; occasions?: Record<string, number>;
  image?: { url: string; webpUrl?: string };
  apiPrice?: { amount: number; currency: string; ml?: number };
  fetchedAt: string;              // sync 날짜
  source: string;                 // 예: "Fragella API"
}

/* perfumes.ko.json — 사람이 작성 (동기화 대상 목록 겸용) */
interface KoPerfume {
  id: string;                     // 우리 id (예: "jo-malone-wood-sage")
  apiQuery: { brand: string; name: string };   // sync 시 API 검색용
  apiId?: string;                 // sync 후 자동 기입
  family: FamilyId; subFamilies: FamilyId[];   // accord-map 제안값을 사람이 확정
  noteKo: Record<string, { ko: string; feel: string; family: FamilyId }>;  // 영문 노트명 → 한국어·일상어
  summary: string; drydown: string; checkPoint: string;
  intensity: 'light'|'medium'|'strong';
  polarizing: 'low'|'mid'|'high';
  moods: string[]; avoidFlags: string[];
  krPrice?: { ml: number; krw: number; checkedAt: string; source: string };  // 국내 공식몰 확인값
  storeQuery: string; channels: string[];
}

/* 앱에서 쓰는 병합 결과 (lib/perfumes.ts) */
interface Perfume extends KoPerfume {
  brand: string; name: string; concentration?: string;
  notes: { top: NoteItem[]; middle: NoteItem[]; base: NoteItem[] };  // NoteItem = { ingredient(ko), feel, family }
  image?: { url: string; credit: string };     // credit = "Fragella"
  price: DisplayPrice;
}

type DisplayPrice =
  | { kind: 'kr';  ml: number; krw: number; checkedAt: string; source: string }       // 우선
  | { kind: 'api'; ml?: number; amount: number; currency: string; fetchedAt: string; source: string }
  | { kind: 'none' };                                                                   // "[확인 필요]"
```

### 가격 표시 규칙 (`lib/price.ts`)
1. `krPrice`가 있으면 → **"50ml 198,000원"** + "2026.10 공식몰 기준"
2. 없고 `apiPrice`가 있으면 → **"해외 기준가 $185 · 100ml"** + "[API 이름] 제공" (환율 변환하지 않음)
3. 둘 다 없으면 → "가격 [확인 필요]"
4. 항상 "가격은 변동될 수 있어요" 함께 표시

### 데이터 작성 원칙
- 목표 **30개**, 우선 **14개(계열당 최소 1개)**로 시작해 동작부터 확인
- 순서: `perfumes.ko.json`에 향수 이름 등록 → `npm run sync`로 API 데이터 받기 → 노트 한국어·일상어, 계열, 국내 정가 채우기
- **시향하기 쉬운 브랜드**(백화점·올리브영·브랜드 매장 입점) 위주로 고른다
- 국내 정가는 브랜드 **국내 공식몰**에서 확인하고 `source`, `checkedAt` 기록
- `summary`, `drydown`, `feel`, `checkPoint`는 우리 말로 새로 쓴다 (외부 리뷰 문장 복사 금지)
- API에 없는 향수는 이미지·노트를 비워 두고 `[확인 필요]` 표시 (다른 사이트에서 가져오지 않음)

### 추천 로직 (`lib/recommend.ts`)
1. `avoids`와 `avoidFlags`가 하나라도 겹치는 향수 제외
2. 점수
   - 향기 칩 계열 = 향수 `family` → +3, `subFamilies`에 있으면 → +2
   - 분위기 칩 id ∈ 향수 `moods` → +2, 분위기 affinity 계열 = 향수 `family` → +1
   - gift 모드 또는 `unsure` → `polarizing: low` +2, `high` −2
3. 점수 순으로 정렬 후, **주 계열이 겹치지 않게** 3개 선택 (부족하면 겹침 허용)
4. 3개를 `family.order` 오름차순 → `intensity`(light → strong) 순 정렬 = **시향 순서**
5. 각 결과에 `matchedReasons`(일치한 칩 라벨, 최대 2개) 포함 → "추천 이유" 문구
- `recommend.test.ts`: 제외 규칙, 3개 반환, 시향 순서 정렬, unsure 시 low 우선 — 최소 4개 테스트

### localStorage
- 키: `scentnote.memos.v1`
- 값: `{ id, perfumeId, rating(1~5), text, createdAt }[]`
- 선택 상태는 저장하지 않는다 (새로고침 시 Home으로)

- **간격:** 4px 단위, 화면 좌우 20, 카드 안쪽 16, 섹션 32
- **모양:** 칩 999 · 버튼 14 (높이 56) · 카드 16 · 시트 24, 그림자는 떠 있는 요소에만
