# spec.md — 시향노트 (SCENT NOTE) MVP

> **이 문서는 2026-10-08 기준 구현에 맞춰 갱신했다.** 처음 계획과 달라진 부분은 각 절의 "(변경)" 표시와 맨 아래 "9. 처음 계획에서 달라진 점"에 모아 두었다. 결정의 이유와 날짜는 `decisions.md` (D-21~D-45)를 본다.
> 배포: https://project-scentnote.vercel.app/ · 저장소: eroonsung/project-scentnote

## 1. 한 줄 소개

> **직접 맡아봐야 아는 향수, 그런데 뭘 맡아봐야 할지 모른다면.**
> 좋아하는 느낌을 일상어 카드로 고르면, **맡아볼 향수 3개(시향 후보)와 맡는 순서**, 각 향의 노트를 쉬운 말과 색으로 알려 주고, 맡아 본 느낌을 별점과 한 줄로 **내 시향 노트**에 남기는 웹 서비스 (데스크톱 우선, 모바일 대응).

이름 뜻: '노트'는 향수의 탑·미들·베이스 노트이자, 나의 시향 기록. 구매 권유·광고·구매 링크는 없다("구매 추천"이 아니라 "시향 후보").

## 2. 누가 쓰나

**타겟:** 향수를 사거나 선물하려고 매장 시향을 앞둔 사람 (향수 경험 수준 무관, 입문자 포함)

| 사용자 | 상황 | 지금 겪는 문제 (설문 근거, 향수 구매 경험자 21명) |
|---|---|---|
| **본인용 구매자** (20~30대 중심) | 백화점·올리브영에 시향하러 가기 전, 또는 매장 앞 | 원하는 향을 말로 설명하기 어려움(48%, 설명해 본 20명 중 "잘 통했다" 0명, "어느 정도 통했다" 15명), 후보가 너무 많아 뭘 맡아야 할지 모름(38%). 둘 중 하나를 꼽은 사람 67% |
| **선물 고르는 사람** | 받는 사람 취향을 잘 모르고, 서프라이즈라 물어보기도 어려움 | "몰라서 무난한 인기 제품" 선택 41%, 상대가 쓰는지 모름 76% |
| **향수 입문자** (추가) | 분위기·향기 용어 자체를 몰라 뭘 골라야 할지 모름 | "분위기나 이런 것도 잘 몰라서 어떤 걸 선택해야 할지 모르겠다"는 피드백 |

사용 순간: **시향하러 가기 전 집이나 회사에서** 미리 후보를 정하고, **매장 앞에서는 휴대폰으로** 다시 확인한다. 박람회는 개인 기기로 접속해 자유롭게 본다(진행 시간 14:00~14:50). 30초 안에 결과가 나와야 한다.

## 3. 화면

### 전체 흐름
```
Home ─┬─ 나를 위한 향수 → Select(분위기 → 향기 → 피하고 싶은 느낌) ─┐
      ├─ 선물할 향수   → Select(그 사람의 분위기 → 피하고 싶은 느낌) ─┼→ Result → (메모) → Notes
      └─ 향수가 처음이에요 → Start(장면 1개) → Select(피하고 싶은 느낌)┘
```
경로: `/` · `/start` · `/similar` · `/select?mode=self|gift&step=1~3[&scene=id]` · `/result` · `/notes`

### 공통 헤더 (변경)
- 왼쪽 로고(시향노트 / SCENT NOTE), 오른쪽 **[내 시향 노트 + 개수] | [처음으로] | [로그인]**.
- 로그인하면 "**닉네임**님의 시향노트 N"으로 바뀌고 오른쪽은 [로그아웃]. 모바일은 로그인 줄이 아래 줄로 내려간다.
- 팝업은 헤더의 흐림 효과에 갇혀 잘리므로 `body`에 직접 그린다.

### S1. Home `/`
- 로고, **시향지 띠**(14개 계열 색 세로 띠), 헤드라인 "직접 맡아봐야 아는 향수, 무엇부터 맡아볼까요?", 서브 문구
- 숫자 강조: 14가지 향 계열 · 3가지 시향 후보(가벼운 향부터) · 광고·구매 링크 0개
- 버튼: **[나를 위한 향수 찾기]**(주) / **[선물할 향수 찾기]**(보조) / 점선 보조 버튼 **[향수가 처음이에요 · 장면 하나만 고르면 돼요]**
- 사용 방법 3단계, 큐레이터 노트, 하단 [지금 큐레이션 시작]

### S1-b. Start `/start` (추가) — 향수 입문자용 장면 고르기
- 장면 카드 6장: 비 온 뒤 숲길 · 갓 세탁한 빨래 · 한여름 바닷가 · 꽃집 앞 봄날 · 따뜻한 카페 · 햇살 가득 과일 가게 (일러스트 + 한 줄 설명 + 미리 채워질 칩)
- 장면을 고르면 분위기 2개 + 향기 1개가 미리 채워지고 **Step 3(피하고 싶은 느낌)**으로 간다. 화면에 "'○○' 장면에 맞춰 분위기와 향기를 미리 골라 두었어요. 위의 01 분위기, 02 향기 단계를 눌러 고칠 수 있어요" 안내.
- 하단 링크 "직접 고르러 가기". 장면 데이터는 `src/lib/scenes.ts`.

### S1-c. Similar `/similar` (추가) — 좋아하는 향수로 찾기
- 향수 이름·브랜드 검색(212개 안에서, 한글·영문) → 하나 선택 → "나를 위해 / 선물용" → [닮은 향 보기]. 목록에 없으면 "느낌 칩으로 찾아보세요" 링크.
- 결과는 `/result`에서 같은 카드로 보여 준다. 닮은 정도 = 분위기 점수 모양 40% + 계열 25% + 노트 겹침 25% + 세기 10% (`src/lib/similar.ts`, D-53). 카드에는 "닮은 향 · 이름 / 닮은 점 · 같은 계열 · 분위기 · 노트". 선물용이면 호불호 적음 +0.04, 큼 −0.06.
- 홈에 "좋아하는 향수가 있어요 · 비슷한 향 찾기" 링크.

### S2. Select `/select`
- 상단 단계 막대 + 단계 이름("STEP 02 / 03"), 오른쪽 **"내 취향 노트" 실시간 패널**(고른 칩, 계열 색 띠, 어울리는 향수 수, [이전]/[다음]/[건너뛰기]/[처음부터 다시 고르기])
- 최소 선택 수 미만이면 [다음] 비활성 + 안내
- 이전 단계로 돌아가면 선택은 유지되지만 **'피하고 싶은 느낌' 선택은 비운다** (앞 단계가 바뀔 수 있어서)
- 패널의 "수정" 버튼, 위쪽 단계 카드, [이전]으로 이전 단계로 돌아가 고칠 수 있다

**self 모드 (3단계)**
| 단계 | 질문 | 칩 | 선택 수 |
|---|---|---|---|
| 1 | 어떤 분위기를 원하세요? | 분위기 칩 13개 | 1~3 |
| 2 | 어떤 향기가 좋아요? | 향기 칩 14개 (계열 색 점 포함) | 1~3 |
| 3 | 피하고 싶은 느낌이 있나요? | 피하고 싶은 칩 8개 | 0~3 (건너뛰기 가능) |

**gift 모드 (2단계)**
| 단계 | 질문 | 칩 | 선택 수 |
|---|---|---|---|
| 1 | 그 사람은 어떤 분위기인가요? | 분위기 칩 13개 + **[잘 모르겠어요 · 호불호 적은 향으로]** | 1~3, 또는 잘 모르겠어요 |
| 2 | 피하고 싶은 느낌이 있나요? | 피하고 싶은 칩 8개 | 0~3 |

- **분위기 칩 충돌 (추가):** 서로 반대인 분위기(시원한↔따뜻한)는 한쪽을 고르면 다른 쪽이 흐려지고 고를 수 없으며, 이유를 아래에 한 줄로 알려 준다. 그 밖의 조합은 막지 않는다(D-51).
- **분위기 예시 (추가):** Step 1(선물 모드 포함)의 [분위기 예시 보기] → 13개 분위기를 일상 장면 예시로 보여 주는 팝업.
- **피하고 싶은 칩 (변경):** 칩마다 "N종"(고르면 빠지는 향수 수, 고른 향기 반영)을 보여 준다. 고른 분위기를 가진 향수가 제외 때문에 45% 미만으로 줄면(예: 묵직한 + 너무 진한 향) "○○ 분위기의 향수 N개 중 M개만 남아요"를 알려 준다(D-56). 고른 향기와 같은 계열을 뜻하는 칩(예: 하얀 꽃 + 꽃향이 강한 향)은 막지 않고 그 계열의 진한 향수만(대표·보조 계열, 태그만 붙은 향수 모두) 거르며, Step 3와 결과 상단에 "선호하는 향으로 '스모키' 향기를 골라서, '스모키한 향'은 진한 향만 제외돼요"라고 알려 준다(D-55).
- **잘 모르겠어요:** 분위기 선택을 비우고 `unsure=true` → 호불호 적은 향(`polarizing: low`) 위주 추천.
- 칩 선택 상태: 분위기 칩 = 잉크 채움 / 향기 칩 = 해당 계열 `-tint` 배경 + 테두리 / 피하고 싶은 칩 = X 아이콘 + 잉크 채움
- 선택 상태는 새로고침하면 사라진다(저장하지 않음). 결과 화면에서 새로고침하면 "아직 고른 느낌이 없어요" 안내 후 처음으로 돌아간다.

### S3. Result `/result` (변경 많음)
- **상단 띠:** 추천 3개 향의 계열 색 3칸
- 라벨(Mono): "YOUR SNIFF LIST · 3" / 제목: "이 순서로 맡아보세요" (gift: "이 순서로 맡아보고 골라 보세요")
- **취향 요약 한 줄:** 고른 칩을 문장으로 (예: "차분한 분위기 · 레몬·귤 향")
- **시향 후보 카드 3개** (시향 순서대로, 가로 배치 · 사이 화살표)

**뒤집기 규칙:** 카드마다 따로 뒤집힌다 · 앞뒤 높이는 같다 · 3D 400ms(`prefers-reduced-motion`이면 약화) · 뒤집기 버튼은 `aria-pressed`, 보이지 않는 면은 `inert` + `aria-hidden` · 뒤집은 뒤 포커스는 보이는 면 제목으로(스크롤 없이) · 카드 배경은 앞면 계열 tint, 뒷면은 그보다 진한 색.

- **의견 상자 (추가):** "이 추천 어땠어요?" 👍 좋아요 / 👎 아쉬워요 → 고른 칩·나온 향수 3개와 함께 Supabase `feedback`에 익명 저장(같은 사람이 다시 누르면 바뀜).
- **시향 팁 박스:**
  1. 1번부터 가벼운 향 순서로 맡아요. 진한 향을 먼저 맡으면 코가 금방 둔해져요.
  2. 시향지에 향수 이름을 적어 두세요.
  3. 마음에 드는 하나만 손목에 뿌리고, 30분 뒤 잔향을 다시 맡아보세요.
  4. 바로 사지 않아도 괜찮아요. 서두르지 말고 잔향까지 확인한 뒤에 정해도 돼요. (변경)
- 하단: [다시 고르기] · [내 시향 노트 보기]
- 조건에 맞는 향이 3개 미만이면 조건을 완화해 채우고 "조건에 딱 맞는 향이 적어 비슷한 향을 함께 보여드려요" 안내. 일부만 맞는 향수가 섞이면(`partial`) "고른 느낌을 모두 가진 향수가 적어, 일부만 맞는 향수도 함께 보여 드려요" 안내
- **이미 별 1~2개를 준 향수는 다시 추천하지 않는다**(화면에 들어올 때의 기록 기준).

### S4. MemoSheet (카드 뒷면 [메모 남기기] → 팝업 + 메모 저장)
- 모바일: 아래 시트 / 데스크톱: 화면 중앙 팝업(너비 480)
- 내용: 순서 번호·향 계열 색 점·향수 이름, 별점 1~5, 한 줄 메모(최대 100자), [저장] · [닫기]
- 이미 메모가 있으면 불러와 수정 (향수당 메모 1개). 저장하면 토스트 "시향 노트에 저장했어요", 버튼이 [메모 수정하기]로 바뀜
- 접근성: `role="dialog"` + `aria-modal`, ESC·바깥 클릭으로 닫기, 닫으면 버튼으로 포커스 복귀
- 안내 문구: "곧 시간에 따라 바뀌는 잔향까지 기록할 수 있어요"

### S5. Notes `/notes` (변경)
- 제목 "내 시향 노트", 정렬(최신/오래된/별점), LOGS 개수

- **카드를 뒤집으면 (추가):** 향수 이미지 + **노트 색 막대**(탑·미들·베이스, 막대나 아래 글자에 올리거나 누르면 그 단계의 노트와 일상어 묘사가 말풍선으로 보임) + 잔향·농도·강도·호불호·계절 + [내 메모 보기 ↻] (이미 시향한 뒤의 기록이라 체크 포인트·가격·시향 가능한 곳·매장 찾기는 빼고, 내 메모·별점은 앞면에만 둔다). **앞면과 뒷면의 카드 크기는 같다**(두 면을 겹쳐 두어 뒤집어도 크기가 변하지 않음)
- 비어 있으면: "아직 맡아본 향이 없어요" + [시향 후보 찾기]
- 하단 안내 카드: "잔향 트래킹 준비 중 — 뿌린 뒤 30분, 2시간, 4시간의 향을 기록하는 기능이 곧 추가돼요"

### S6. 선택 로그인 (추가) — 닉네임 + 숫자 4자리
- 로그인하지 않아도 모든 기능을 쓸 수 있다(메모는 익명으로 저장). 로그인은 다른 기기에서도 노트를 보기 위한 선택 사항.
- 헤더 [로그인] 또는 Notes 계정 상자 → 팝업(탭: 닉네임 만들기 / 로그인). 닉네임 2~8자(한글·영문·숫자·밑줄, 중복 불가), 숫자 4자리. 휴대폰 번호 등 개인정보는 받지 않는다.
- 만들기·로그인하면 이 기기의 노트가 그 닉네임에 함께 저장된다. 숫자를 잊으면 복구할 수 없다(화면에 안내).
- **로그아웃하면 이 기기의 노트를 지운다**(닉네임 계정에는 남아 있음). 로그인한 채 10분 동안 아무것도 안 하면 자동 로그아웃.

### 스키마 (`src/types.ts`)
```ts
type FamilyId = 'citrus'|'fruity'|'aqua'|'green'|'aromatic'|'floral'|'whiteFloral'
  |'powdery'|'musk'|'spicy'|'woody'|'amber'|'gourmand'|'leather';

interface NoteItem { en: string; ko: string; feel: string; family: FamilyId }
interface KrPrice { ml: number; krw: number; checkedAt: string | null; source: string | null }

interface Perfume {
  id: string; brand: string; brandKo: string; name: string; nameKo: string
  concentration: string | null                      // EDT, EDP, EDC, Parfum, Cologne …
  notes: { top: NoteItem[]; middle: NoteItem[]; base: NoteItem[] }
  family: FamilyId; subFamilies: FamilyId[]
  moods: string[]                                   // 분위기 점수가 1 이상인 칩 id (점수 높은 순, 향수마다 3~6개)
  moodScores?: Record<string, 1 | 2>                // 분위기 정도: 2 = 대표, 1 = 은은함 (0은 생략). 엑셀 mood_scores 열 "calm:2,clean:1" (D-52)
  avoidFlags: string[]                              // 피하고 싶은 칩 id
  intensity: 'light'|'medium'|'strong'; polarizing: 'low'|'mid'|'high'
  seasonOccasion: string; summary: string; drydown: string; checkPoint: string
  krPrice: KrPrice | null
  storeQuery: string; channels: string[]
  image: { file: string; source: string | null } | null
  dataStatus: 'draft' | 'verified'
}
interface Selection { mode: 'self'|'gift'; moods: string[]; objects: string[]; avoids: string[]; unsure: boolean }
interface Memo { id: string; perfumeId: string; rating: number; text: string; createdAt: string }
```

### 가격 표시 규칙 (`lib/price.ts`) (변경)
1. 국내 정가가 있으면 → **"50ml 198,000원"** + "2026.10 공식몰 기준"
2. 없으면 → "가격은 매장에서 확인해 보세요" (환율 변환·해외 가격·"확인중" 문구는 쓰지 않는다)
3. 카드 아래 "가격은 공식몰에서 확인한 값이에요. 가격은 변동될 수 있어요." 표기

### 추천 로직 (`lib/recommend.ts`, `lib/avoid.ts`) (변경)
1. **제외:** 피하고 싶은 칩에 해당하는 향수(`avoid.ts` 규칙)와, 별 1~2개를 준 향수를 뺀다.
2. **점수:** 향기 칩 계열 = 향수 `family` → +3, `subFamilies`에 있으면 → +2 / 분위기 칩 점수가 향수 `moodScores`에 있으면 대표(2점) → +2, 은은함(1점) → +1, 분위기 affinity 계열 = 향수 `family` → +1 / 피하고 싶은 태그가 붙은 채 남은 향수 → −1 / gift 또는 `unsure` → `polarizing: low` +2, `high` −2. 점수가 같으면 선택 조합마다 고정된 섞인 순서로 가르며, 같은 점수끼리는 이미 뽑힌 것과 세기·계열이 다른 향수를 먼저 쓴다.
3. **3개 고르기 (단계별 확장):** 고른 분위기를 **모두** 가진 향수(고른 향기도 맞는)를 먼저 뽑고, 3개가 안 되면 분위기가 하나 덜 맞는 향수까지, 그래도 모자라면 하나라도 맞는 향수까지 넓힌다. 고른 분위기와 서로 어울리지 않는 분위기 태그를 가진 향수는 마지막에만 쓴다. **향기 칩을 2개 이상 골랐으면 칩마다 그 계열(대표 계열) 향수를 1개씩 먼저 확보한다**(반대 분위기 태그가 없고 분위기를 1개 이상 가진 향수 중 분위기를 많이 가진 것. 그런 향수가 없으면 넣지 않음). 4단계: 향기가 맞는 향수 중 반대 분위기 태그가 있는 것, 5단계: 그 밖의 점수 > 0 향수. **같은 계열이 겹쳐도 된다.**
4. **시향 순서:** `intensity`(light→strong) → `family.order` → 농도(EDC·코롱 → EDT → EDP → 퍼퓸) 순으로 정렬. 모두 같으면 점수 순.
5. 각 결과에 일치한 칩 이름 전부(`reasons`)와 "분위기 N개 중 M개 · 향기 N개 중 M개"(`moodMatch`, `scentMatch`)를 담아 카드에 보여 준다.
- 점수 값은 AI가 정한 초안이며 실제 사용 반응(👍/👎)을 보며 조정할 수 있다.
- `recommend.test.ts`: 3개 반환, 제외 규칙, 시향 순서, 단계별 확장, 동점 처리, 향기와 피하고 싶은 칩, 충돌 분위기 등 (현재 47개 테스트, `similar.test.ts` 포함).

  - Select: 2단 — 왼쪽(약 60%) 질문·칩, 오른쪽(약 40%) **"내 취향 노트" 실시간 요약 패널**(고른 칩이 계열 색 점과 함께 쌓이고, 아래 [다음] 버튼). 모바일은 요약 패널이 하단 고정 바로 바뀜
  - Result: 상단 3색 띠 + 제목·취향 요약 → **카드 3장을 가로로 나란히(①②③ 왼쪽→오른쪽 = 시향 순서)**, 카드 사이 화살표로 순서 표시 → 의견 상자(👍 좋아요 / 👎 아쉬워요) → 시향 팁 박스. 모바일은 세로로 쌓임
  - Notes: 위쪽 계정 상자(닉네임 만들기·로그인) + 메모 카드 3열 그리드 (모바일 1열). 카드는 높이가 서로 달라도 되고(`items-start`), 뒤집으면 향수 이미지·상세 정보가 나온다
  - MemoSheet: 데스크톱은 화면 중앙 모달(너비 480), 모바일은 아래 시트
- **모션:** 결과 카드 60ms 간격 등장, 노트 막대 채워짐, 칩 선택 시 살짝 커짐(scale 1.03), 200ms
- **아이콘:** 선 아이콘(inline SVG). 이모지는 쓰지 않는다 (예외: 결과 화면 의견 버튼의 👍👎, 별점 표시의 ★)
- **이미지:** 향수병 사진은 직접 찾아 `public/perfumes/`에 넣은 것만 쓴다(공식 사이트·판매처 이미지, 출처는 엑셀 `image_source_url`에 기록). 카드 앞면 가운데 큰 사진(216×288), 뒷면·노트 카드에서는 작게. 이미지가 없으면 향 계열 색 병 모양 플레이스홀더. 브랜드 로고는 쓰지 않음
- **참고 시안(초기):** 디자인 캔버스 "시향 후보 추천 브랜드 시안"의 v2 보드 (컬러·화면 예시)
